Case 1. 모든 자료형에서 표현이 불가능한 경우 ➡️ 정답 값을 XX로 나눈 나머지를 출력하세요.
Case 2. int로는 불가능하고 long으로 표현 가능한 경우 ➡️ 별도 언급이 없습니다.

🚨 이럴 때 의심해보세요!

## 2. Scanner vs BufferReader
코딩테스트에서 입력을 받는 방법은 BufferReader가 더 좋다.  
**입력받는 시간이 더 빠르기 때문이다.**  

🚨 이럴 때 의심해보세요! 
> **시간초과**로 실패

```java
// Scanner
Scanner sc = new Scanner(System.in);
int a = sc.nextInt();
int b = sc.nextInt();
int c = sc.nextInt();

// BufferReader
BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
StringTokenizer st = new StringTokenizer(br.readLine());

int a = Integer.parseInt(st.nextToken());
int b = Integer.parseInt(st.nextToken());
int c = Integer.parseInt(st.nextToken());
```

## 3. ++i vs i++
증감연산자 : 전위연산자 vs 후위연산자  

**전위연산자**
```java
int A[] = new int[3];
int i = 1;
A[++i] = 10;
```
1. i가 2로 증가
2. A[i]에 10 저장

**후위연산자**
```java
int A[] = new int[3];
int i = 1;
A[i++] = 10;
```
1. A[i]에 10 저장
2. i가 2로 증가

## 4. 오름차순 정렬 vs 내림차순 정렬
**오름차순 정렬**
```java
int A[] = {5, 3, 2, 4, 1};
Arrays.sort(A);
System.out.println(Arrays.toString(A));
```

**내림차순 정렬**
```java
// 방법 1
Integer A[] = {5, 3, 2, 4, 1};
Arrays.sort(A, Collections.reverseOrder());
System.out.println(Arrays.toString(A));

// 방법 2
int A[] = {5, 3, 2, 4, 1};
Integer[] tmp = Arrays.stream(A).boxed().toArray(Integer[]::new);
Arrays.sort(tmp, Collections.reverseOrder());
System.out.println(Arrays.toString(tmp));
```

## 5. Comparable
**`정렬 기준이 여러 개`**일 때 사용한다.  
_예시) 영어 점수가 높은 학생 순으로 정렬하되 영어 점수가 같으면 수학점수가 높은 학생을 선순위로 정렬하여 주세요!_
```java
class Score implements Comparable<Score> {
    int english;
    int math;
    
    public Score(int english, int math) {
        super();
        this.english = english;
        this.math = math;
    }
    
    @Override
    public String toString() {
        return "Score [english=" + english + ", math=" + math + "]";
    }
    
    @Override
    public int compareTo(Score o) { // 양수리턴 -> 내림차순, 음수리턴 -> 오름차순
        if (this.english != o.english) { 
            return o.english - this.english;
        }
        return o.math - this.math;
    }
}
```

```java
ArrayList<Score> A = new ArrayList<>();

A.add(new Score(80, 100));
A.add(new Score(100, 100));

A.add(new Score(100, 90));

Collections.sort(A);

for (int i = 0; i < A.size(); i++) {
    System.out.println(A.get(i).toString());
}
```

## 9. 정답을 XX로 나눈 나머지를 출력하세요
- 정답이 변수가 표현하는 범위를 넘어가는 경우
- MOD 연산의 특성을 이용

> MOD 연산의 특성
> 1️⃣ 덧셈에 대한 분배 법칙이 성립한다.
> 2️⃣ 뺄셈에 대한 분배 법칙이 성립한다.
> 3️⃣ 곱셈에 대한 분배 법칙이 성립한다.
> 4️⃣ 나눗셈에 대해서는 분배 법칙이 성립하지 않는다.

즉, "정답을 XX로 나눈 나머지를 출력하세요"라는 문제는 정답을 구하고 % 연산을 하는게 아니라 step마다 % 연산을 하면서 문제를 풀어야 한다.  
왜냐하면, 중간 단계에서 이미 표현 범위를 증가할 수 있다.
